Clasificación de cuentas: Fijo / Variable

Variable: sube y baja con lo que se vende (insumos). Fijo: se paga igual aunque se venda poco (alquiler, sueldos). Mixto: una parte de cada uno (indica el % variable). Excluir: gastos no recurrentes que distorsionarían el cálculo. Se muestran solo las cuentas con movimiento en la base elegida; el cambio aplica a todos los meses.
